拿不到路径：Electron 已移除 File.path，renderer 里的 <input type="file"> 只给出 File 对象，没有任何磁盘路径可传。

也不能让主进程弹对话框：在这个无窗口的 utility 进程里 spawn 一个 WinForms 打开文件对话框不工作——对话框永远不会被创建，ShowDialog 直接阻塞（真踩过）。

可行做法：面板自己把图片读成 bytes 交上来，写进插件自己的 data 目录，运行时主题里引用那个绝对路径；宿主会把它改写成 plugin-asset: URL，这是运行时主题携带图片的既定方式。

宿主对主题资源有硬限制：4MB 上限（features/appearance/glass.js 的 WALLPAPER_MAX_BYTES = 4 * 1024 * 1024）加自己的扩展名白名单（png / jpg / jpeg / webp / avif / svg）。提前按同样的规则预检，才能把一次被拒的 themes.upsert 变成一句用户能照着改的话（「图片超过 4 MB，宿主会拒绝这个主题资源」）。

壁纸一次只留一张：别的格式的残留会占着磁盘，还可能被旧设置引用。

文件：features/glass/index.js、features/appearance/glass.js
